# Self-Driving Car Simulation 🚗💡  

This repository contains the code and resources for building a **Self-Driving Car Simulation** step by step.  
The project is structured as a learning journey, where each part of the course introduces new concepts and code.  

---

## 📚 Course Structure  

The code will be released progressively in the following parts:

1. **Car Driving Mechanics**  
   - Implement the basic car object and physics (acceleration, steering, braking, friction).  

2. **Road Definition**  
   - Define road lanes, boundaries, and paths for cars to follow.  

3. **Artificial Sensors**  
   - Add simulated sensors to detect obstacles and surroundings.  

4. **Collision Detection**  
   - Implement collision logic between the car and road boundaries/traffic.  

5. **Traffic Simulation**  
   - Add AI-controlled cars to simulate realistic driving conditions.  

6. **Neural Network**  
   - Introduce a simple neural network to control the self-driving car.  

7. **Visualizing Neural Networks**  
   - Build a visualizer to understand how the neural network processes inputs and outputs.  

8. **Optimizing Neural Networks**  
   - Apply techniques to improve training efficiency and performance.  

9. **Fine-Tuning**  
   - Adjust hyperparameters and weights for better driving results.  

10. **Live Stream Variant**  
    - Extend the project to a live stream setup for real-time visualization and experimentation.  

---

## 🛠️ Tech Stack  

- **JavaScript / TypeScript** (core logic & simulation)  
- **HTML5 Canvas** (visualization)  
- **Neural Networks** (vanilla implementation, no external ML frameworks)
